# Claude Code 以外のエージェントへの注記

以下のグローバル指示は Claude Code のために書かれた文面をそのまま共有している。**意図はあなたにも等しく当てはまるが、名指しされている仕組みの一部は Claude Code にしか無い。** 差分はこの節だけで、以下を読み替えてから本文に進むこと。

- **`~/.claude/rules/`** は実在するディレクトリで、中身(`common/` とドメイン別ディレクトリ)もそのとおりにある。ただしこれを**自動で読み込むのは Claude Code だけ**。あなたには自動ではロードされないので、扱っている言語・領域に対応するファイルがあるかを自分で確認し、必要なものを明示的に読むこと。
- **`AskUserQuestion`** は Claude Code のツールで、あなたには無い。構造化された選択肢を提示するという意図は保つ — 選択肢に番号を振り、それぞれの意味と推奨をテキストで明示して尋ねること。
- スラッシュコマンド(`/harness-reflect` など)・`mcp__*` のツール名・`~/.claude/` 配下のフック実行経路は、いずれも Claude Code のセッションにしか存在しない。名前が出てきても、あなたが実行できるものとして扱わないこと。
