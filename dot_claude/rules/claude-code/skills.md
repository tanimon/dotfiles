# スキルの扱い

Claude Code 専用のルール。`~/.codex/AGENTS.md` には連結しない。

## 自分のスキル一覧に無い名前を「未インストール」と断定しない

スキルやコマンドの案内(別のスキルの手順、README など)に出てくる `/<name>` が自分のスキル一覧に無くても、
未インストールと判断しない。ユーザーだけが起動できるスキル(`disable-model-invocation`)はモデルに見える一覧に出ない。
その段階に来たら「`/<name>` を実行してください」とユーザーに促して待ち、別のスキルでの代用を提案しない。

**理由:** `/to-spec` などを一覧に無いことから「この環境に入っていない」と断定し `writing-plans` での代用を提案したが、
実際にはインストール済みで、ユーザー自身が起動するスキルだった。プロジェクト単位の memory に残しても、
別の worktree や別リポジトリのセッションには届かない。
