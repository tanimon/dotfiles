# Evaluator のパスの一覧(ADR 0011)。自己改善ループの PR がここに載ったパスに触れると、
# scripts/check-evaluator-guard.sh が CI で失敗させる。人の PR は判定しない。
# 1 行 1 パス(リポジトリルートからの相対)。末尾が / の行はそのディレクトリ配下すべて、
# それ以外は完全一致。+ で始まる行(末尾 / のディレクトリ)は追加だけを許し、ループの PR はそこへ新しい
# ファイルを足せるが、既存のファイルの変更・削除・移動は落とす。# で始まる行と空行は無視する。
#
# Evaluator のパスを足し忘れたことを機械的に検出する仕組みは無く、足す PR のレビューで確かめる。
# ガードは base 側の版を読むので、足した行はマージ後に効く。

# ガード自身。一覧・判定・テストを書き換えられると、ガードを外せる

scripts/check-evaluator-guard.sh
test/check-evaluator-guard.bats
# ガードのテストが依存するもの。assert_failure などや bats の版を差し替えると、テストが空振りで緑になる

package.json

# ガードを CI に配線しているもの。job や recipe を外す・ツールを差し替えるとガードが走らない。

# 保証は書き換えが差分として人のレビューに見えるところまで(check-evaluator-guard.sh のヘッダ)
