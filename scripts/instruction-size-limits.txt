# ルールと指示のファイルと skill の本文(SKILL.md)のファイルごとのサイズ上限(ADR 0011 の肥大の歯止め)。
# scripts/check-instruction-size.sh が読み、超えたファイルがあると just lint と CI が落ちる。
# 1 行 1 件で「<パス> <最大行数> <最大バイト数>」を空白で区切る(空白を含むパスは登録できない)。
# パスが * の行はルールと指示の既定値、skill:* の行は SKILL.md の既定値(個別の上限はどちらにも優先する)。
# # で始まる行(字下げしてもよい)と空行は無視する。
#
# skill の既定値をパスのパターンごとの既定値(例: dot_claude/skills/** の行)にしないのは、パターン同士が
# 重なるとどの行が勝つかが行の順序で決まり、重複行を後勝ちにしない規則と同じ穴が開くため。SKILL.md かどうか
# はファイル名だけで決まり、どちらの既定値が当たるかに順序は関わらない。SKILL.md があるのに skill:* の行が
# 無いと、* の既定値に落とさず exit 2 にする(根拠の違う 200 行の値で skill を測らない)。
#
# 「render:<テンプレート> <最大行数> <最大バイト数>」の行は、テンプレートのソースではなく合成後の出力の上限。
# 最大行数には - を書ける(行数を縛らない)。既定値は当てはまらないので、行ごとに明示する。
# 描画は test/rendered-instruction-size.bats が test/fixtures/chezmoi-*.toml のすべての profile で行い、
# scripts/check-instruction-size.sh --rendered で測る。合成後の出力を測る対象を増やすときはここに 1 行足す。
#
# 既定値の根拠:
# - 200 行: Claude Code 公式ドキュメント(https://code.claude.com/docs/en/memory)が CLAUDE.md の目安を
#   「target under 200 lines per CLAUDE.md file」とし、長いほど遵守が落ちるとしている。
#   paths の無い .claude/rules/*.md も CLAUDE.md と同じく起動時に読み込まれるので、同じ値を使う。
# - 32768 バイト: Codex は AGENTS.md を project_doc_max_bytes(既定 32 KiB)で黙って切り捨てる。
#   行数だけでは 1 行が長いファイル(段落を 1 行で書く CLAUDE.md)を縛れないので、バイト数も見る。
#
# skill の既定値の根拠(* の根拠はどちらも起動時に読み込まれるファイル向けで、skill には当てはまらない)。
# どちらも Claude Code 公式ドキュメント(https://code.claude.com/docs/en/skills)による:
# - 500 行: 「Keep SKILL.md under 500 lines. Move detailed reference material to separate files.」としている。
#   skill は一度読み込まれると以降のターンも context に残り、毎ターンのコストになる。
# - 15000 バイト: 「Skill content lifecycle」の節が、auto-compaction の後は各 skill の先頭 5,000 トークン
#   だけを再添付する(再添付される skill 全体で 25,000 トークン)としている。超えた分は圧縮後に黙って
#   切り捨てられる(* の 32768 バイトが Codex の切り捨てを根拠にしているのと同じ種類の根拠)。
#   トークン数はオフラインで測れないので、1 トークンを 3 バイトと見積もってバイト数に換算した。日本語は
#   UTF-8 で 1 文字 3 バイトで、ほぼ 1 文字 1 トークンになり、英語やコードは 1 トークンが 3 バイトより長い
#   ので、日本語が中心の SKILL.md でも 5,000 トークンに収まる側に倒れる見積もりにしている。
#   行数が少なくても 1 行が長い SKILL.md(dot_claude/skills/deliver/SKILL.md など)があるので、
#   バイト数も見る。
# 日本語が中心の SKILL.md は 1 行あたりのバイト数が多く(500 行 × 約 100 バイト ≒ 50 KB)、500 行より先に
# 15000 バイトに当たる。実際に効くのはほぼバイト数の上限で、500 行は 1 行が短い SKILL.md の歯止めになる。
#
# 個別の上限は、既定値を超えているファイルの実測値(行数・バイト数とも)。上げる変更は差分として
# 人のレビューに見える。ファイルを削ったら値も下げる(下げ忘れは検査しない。削った分の余白は
# 次の書き足しに使えてしまう)。自己改善ループの PR がこの一覧を変えると Evaluator ガードが
# 落とす(scripts/evaluator-paths.txt)ので、ループがこれらのファイルに書き足すには同じだけ削る。
#
# 上限はファイルごとに測るので、グローバル指示はテンプレートのソース(dot_claude/CLAUDE.md.tmpl と
# .chezmoitemplates/agent-instructions-common)を別々に測る。合成後の出力は各ソースが上限内でも
# 超えうるので、render: の行で別に測る:
# - ~/.codex/AGENTS.md(dot_codex/AGENTS.md.tmpl): 共有本文に dot_claude/rules/common/ を連結するので、
#   ルールを足すたびに太る。Codex が切り捨てるのは 32 KiB を超えた分なので 32768 バイトまで。
#   行数は縛らない(連結した rules で 200 行を超えるのは想定どおり)。
# - ~/.claude/CLAUDE.md(dot_claude/CLAUDE.md.tmpl): 起動時に読み込まれる 1 ファイルなので既定値と同じ値。
#
# リポジトリのルートの AGENTS.md(生成物。~/.codex/AGENTS.md とは別物)の 32 KiB 超えは意図した
# 設計で、Codex の切り捨てが 1 モジュールの内側で起きる並びを test/harness-instructions.bats が
# 守っている。ここでは増加を止めるためだけに登録する。

* 200 32768
skill:* 500 15000

CLAUDE.md 237 52243
.claude/rules/shell-scripts.md 221 11866
dot_claude/scripts/CLAUDE.md 548 60046
dot_config/nono/CLAUDE.md 42 39472

render:dot_codex/AGENTS.md.tmpl - 32768
render:dot_claude/CLAUDE.md.tmpl 200 32768
