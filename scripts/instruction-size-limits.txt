# ルールと指示のファイルごとのサイズ上限(ADR 0011 の肥大の歯止め)。
# scripts/check-instruction-size.sh が読み、超えたファイルがあると just lint と CI が落ちる。
# 1 行 1 件で「<パス> <最大行数> <最大バイト数>」を空白で区切る(空白を含むパスは登録できない)。
# パスが * の行は既定値。# で始まる行(字下げしてもよい)と空行は無視する。
#
# 既定値の根拠:
# - 200 行: Claude Code 公式ドキュメント(https://code.claude.com/docs/en/memory)が CLAUDE.md の目安を
#   「target under 200 lines per CLAUDE.md file」とし、長いほど遵守が落ちるとしている。
#   paths の無い .claude/rules/*.md も CLAUDE.md と同じく起動時に読み込まれるので、同じ値を使う。
# - 32768 バイト: Codex は AGENTS.md を project_doc_max_bytes(既定 32 KiB)で黙って切り捨てる。
#   行数だけでは 1 行が長いファイル(段落を 1 行で書く CLAUDE.md)を縛れないので、バイト数も見る。
#
# 個別の上限は、既定値を超えているファイルの実測値(行数・バイト数とも)。上げる変更は差分として
# 人のレビューに見える。ファイルを削ったら値も下げる(下げ忘れは検査しない。削った分の余白は
# 次の書き足しに使えてしまう)。自己改善ループの PR がこの一覧を変えると Evaluator ガードが
# 落とす(scripts/evaluator-paths.txt)ので、ループがこれらのファイルに書き足すには同じだけ削る。
#
# 上限はファイルごとに測るので、グローバル指示はテンプレートのソース(dot_claude/CLAUDE.md.tmpl と
# .chezmoitemplates/agent-instructions-common)を別々に測る。合成後の ~/.claude/CLAUDE.md は
# 各ソースが上限内でも超えうるので、test/global-instructions.bats が合成後を既定値で測っている。
#
# AGENTS.md(生成物)の 32 KiB 超えは意図した設計で、Codex の切り捨てが 1 モジュールの内側で起きる
# 並びを test/harness-instructions.bats が守っている。ここでは増加を止めるためだけに登録する。
